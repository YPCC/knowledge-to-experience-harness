# Visual Style Skill — 3Blue1Brown-Inspired

Reusable guidance for generating clear, progressive, visually reasoned explainers.

## Principles

- **Clarity over decoration**: Every visual element must carry meaning.
- **Progressive disclosure**: Start simple, add complexity one idea at a time.
- **Visual metaphors**: Prefer geometric, flow, or structural analogies that map to the concept.
- **Color with purpose**: Consistent palette; color encodes categories or states.
- **Motion that teaches**: Transitions reveal relationships (not just eye candy).
- **Text is sparse**: Narration carries the words; on-screen text is labels or key equations.

## Target Aesthetic

- Clean white or soft dark background.
- Soft blues, teals, and accent oranges/purples (matching the harness diagram where relevant).
- Flat or lightly shaded shapes; avoid heavy 3D unless the concept requires it.
- Typography: clean sans-serif, high contrast.

## Implementation Notes

- Slide-based generation + generated imagery + ffmpeg transitions for speed.
- Manim or code-driven animation for math-heavy or structural topics when feasible.
- Always produce intermediate frames/assets for re-use and review.

This skill can be swapped or refined per domain (healthcare, engineering, business).
